# SaaS-O-Matic: frontend

Dashboard en Angular 22 (spec 005). Las instrucciones de arranque, las decisiones visibles y los supuestos están en el [README principal](../README.md); las herramientas y versiones, en el ADR 0010 (`ai-workspace/architecture/adr/`).

- `npm start`: servidor de desarrollo en `http://localhost:4200`, con el backend en `http://127.0.0.1:8000`.
- `npm test`: tests en una sola pasada.
- `npm run lint`: lint con las reglas de capas del ADR 0010.
- `npm run build`: compilación de producción en `dist/`.
